# Spookie

Low-poly spooky top-down 3D game built with three.js.

Run: `python3 -m http.server 8000` then open http://localhost:8000

Controls: WASD / arrow keys, or touch and drag anywhere (virtual joystick) on mobile.

Single-file build for phones/hosting: `node build.mjs` -> `dist/spookie.html` (three.js + game inlined).
